# Product Brief

- App name: Shadowbridge Prototype
- One-line pitch: Drag the sun so block shadows form a path; Pip can only walk in shadow.
- Target user: The Product Owner and a few friends, playing on iPhone. Later: fans of calm puzzle games (Monument Valley, Gris).
- Problem: The full Shadowbridge game is an 8+ week project. Nobody knows yet if its core mechanic (control the light, not the character) is fun. This prototype answers that in one weekend.
- Success looks like: A friend finishes all 3 levels on an iPhone without help and wants to play more.
- Long-term vision (not in this prototype): Shadowbridge, a colorful 3D puzzle game for PC/Steam and later mobile.
- Out of scope: 3D graphics, sound, menus beyond level select, block rotation, moving blocks, stars, accounts, servers, store release.
